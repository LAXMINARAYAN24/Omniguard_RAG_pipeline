## 1.1 Overview

Here's the Overview section, matching the template's Chapter 1 structure:

> Retrieval-Augmented Generation (RAG) systems combine large language models with an external retrieval index so that generated answers can be grounded in verifiable source documents rather than relying purely on the model's parametric memory. This grounding, however, introduces a new attack surface: an adversary who can influence either the corpus being retrieved from or the query that triggers retrieval can steer the system's final answer without ever touching the model's weights. Recent literature (2025–2026) documents both increasingly effective poisoning attacks — compound query-and-corpus attacks such as PIDP, and semantically fluent, detection-evading poison such as SilentRetrieval — and a corresponding sequence of defenses: spectral pre-ingestion filters (DRS), query-time consensus reshaping (ShieldRAG), adversarially trained retrievers with counterfactual verification (RAGuard), and multi-ring defense-in-depth pipelines (TriShieldRAG). Read together, these six papers reveal that no single existing defense is layered enough: spectral filters offer no query-time protection, single-document counterfactual verification is blind to two or more colluding poison documents, and multi-ring pipelines can still collapse when every ring evaluates the same already-poisoned retrieved context.
>
> This project implements and empirically evaluates **OmniGuard-RAG**, a four-ring defense-in-depth framework built to close each of these gaps directly: a query-path guard that strips adversarial suffixes before retrieval, a spectral ingestion filter that screens the corpus, a risk-aware router that escalates only genuinely suspicious retrievals to deeper verification, and a Group-Wise Counterfactual Consensus mechanism that generalizes leave-one-out verification to leave-*group*-out, so that multiple mutually corroborating poison documents are caught together rather than individually. The system is benchmarked end-to-end on real text and real TF-IDF embeddings against five representative baselines under six attack regimes, including a fully camouflaged, query-targeted collusion attack constructed to be indistinguishable from genuine content at both the lexical and embedding level.
